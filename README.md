
# ScopeMovie
> 🚧 **Work in progress:** this project is still under development. Some features are not finished yet.
ScopeMovie is a movie and TV show discovery web app built with React, Vite and Tailwind CSS, using data from the TMDB API. Browse what's trending, search for any title, explore content by genre, and keep your own watchlist.

## Features

- [x] Home page with trending movies
- [x] Live movie search
- [x] Poster fallback and loading/error states
- [ ] Movies page with genre sections
- [ ] TV Shows page with genre sections
- [ ] Sign up / Sign in
- [ ] My List (save favorites)

## Tech Stack

- React + Vite
- Tailwind CSS
- TMDB API

## Getting Started

1. Clone the repository and install dependencies:
```bash
   npm install
```
2. Create a `.env` file in the project root with your TMDB Read Access Token:

3. Start the dev server:
```bash
   npm run dev
```
